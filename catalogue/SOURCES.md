# Catalogue sources

Every USB id and module path in `catalogue.json` traces to a source below. Accessed 2026-10-22.

No vendor publishes a PKCS#11 path list for these tokens, and the Hypersecu and CA download pages checked give installer names only. Paths therefore come from projects that load these drivers in the field; a path backed by two or more of them is treated as confirmed. A wrong path costs one failed existence check, while a wrong USB id routes a token to the wrong driver, so ids need a source that names the product.
